# Homelab Service Manager

Full stack web app that monitors and manages services that runs in a self hosted homelab environment.

## Project Goals

My goal with this project is to provide a centralized interface for my different homelab services while tracking the health of those services, and managing my containerized applications.

## Planned Features

- Service Monitoring
- Service Health Checks
- Historical uptime and performance metrics
- Search and Filtering
- User authentication
- REST API
- Docker container integration
- System resource monitoring
- Event and incident tracking

## Technology Stack

- Python
- Django
- PostgreSQL
- HTML/CSS
- Javascript
- Docker
- Docker Compose
- Git/Github
